Security and robustness update to the v0.1.0 pre-release. **Upgrade recommended.**

**Pre-release.** An engineering tool for demonstration and controlled trials, not for unattended production use.

### Security
- Quick start and `INSTALL.txt` verify the archive's independently supplied digest with `sha256sum` before anything is extracted or run.
- `install` refuses symbolic links at destination files and parent directories, and bundle files that would overwrite `.dockyard/`.
- `install` stages and validates (risk audit, image load, image ID check) before touching the target; a rejected upgrade leaves the existing installation unchanged, and files are replaced atomically.

### Fixed
- Corrupted or truncated bundles are always refused with a verification error (exit 2) before anything is loaded.
- The real-Docker acceptance corruption fixture now exercises the integrity check.

### Changed
- The release workflow requires full CI to pass and smoke-tests the built wheel and sdist before publishing.

Limits are unchanged from v0.1.0 (see its notes). Checksums are in `SHA256SUMS`. See the [changelog](https://github.com/5K-bit/Dockyard/blob/v0.1.1/CHANGELOG.md) for details.
